# Titanic Survival Prediction

A beginner machine-learning classification project using the Titanic dataset available through OpenML.

## Objectives
- Load and inspect passenger data
- Handle missing values
- Engineer features
- Train a Logistic Regression classifier
- Evaluate accuracy and classification metrics

## Technologies
Python, Pandas, Scikit-learn

## Run
```bash
pip install -r requirements.txt
python train.py
```

The first run requires internet access because the dataset is fetched from OpenML.
